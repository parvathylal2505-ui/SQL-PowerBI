This project analyses audience views, ratings, and trends of 3,000+ Indian movies released between 2016 and 2026, using data from TMDB and IMDb. The raw data was cleaned and transformed in Excel Power Query, handling missing values, duplicates, and inconsistent formats. SQL queries were used to explore votes, ratings, and release trends across genres, languages, and years. The results are presented in an interactive Power BI dashboard with DAX measures, KPI cards, slicers, and navigation buttons.
